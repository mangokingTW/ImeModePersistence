為什麼需要它Why you need it为什么需要它

Windows 沒有任何設定能維持「轉換模式」No Windows setting covers the conversion modeWindows 没有任何设置能维持「转换模式」

Windows 的 IME 狀態是逐執行緒的。切到另一個視窗,轉換模式就回到 IME 預設 —— 中文鍵盤就是變回中文。於是你按 Shift 切英數、換個視窗,又在打中文了。「為每個應用程式視窗設定不同的輸入法」那個設定治不了這個 —— 它只管「用哪個輸入法」,不管「中/英模式」。 Windows keeps IME state per thread. Move to another window and the conversion mode reverts to the IME's default — for a Chinese keyboard, that means Chinese. The “different input method for each app window” setting does not fix this: it governs which method is active, not whether it is in native or alphanumeric mode. Windows 的 IME 状态是逐线程的。切到另一个窗口,转换模式就回到 IME 默认 —— 中文键盘就是变回中文。于是你按 Shift 切英数、换个窗口,又在打中文了。「为每个应用窗口设置不同的输入法」那个设置治不了这个 —— 它只管「用哪个输入法」,不管「中/英模式」。

維持你選的中/英模式,就是這個工具的第一個用途;第二個是把特定程式釘在某個輸入語言 —— 包含任何設定都搆不到的那種(直接讀原始輸入的全螢幕遊戲)。 Carrying that native/alphanumeric mode is this utility's first purpose. Its second is pinning a program to an input language — including the kind no setting can reach, like a fullscreen game reading raw input. 维持你选的中/英模式,就是这个工具的第一个用途;第二个是把特定程序钉在某个输入语言 —— 包含任何设置都够不到的那种(直接读原始输入的全屏游戏)。

跨視窗維持模式Mode persistence跨窗口维持模式

在 A 視窗打中文 → 切到 B 仍是中文;按 Shift 變英數 → 切到 C 仍是英數。跟著你最近一次刻意的選擇走,可從托盤關閉。Type Chinese in A → B stays Chinese; press Shift for alphanumeric → C stays alphanumeric. Follows your most recent deliberate change; toggleable from the tray.在 A 窗口打中文 → 切到 B 仍是中文;按 Shift 变英数 → 切到 C 仍是英数。跟着你最近一次有意的选择走,可从托盘关闭。

每 App 綁定輸入語言Per-app language binding每 App 绑定输入语言

把終端機綁英文、Word 綁中文。支援完整路徑 / 檔名 / 視窗類別 / 萬用字元;可拖曳排序(最上者優先)、套用一次、預設語言。Bind a terminal to English, Word to Chinese. Full path / file name / window class / wildcards; drag to reorder (topmost wins), apply-once, and an optional default.把终端绑英文、Word 绑中文。支持完整路径 / 文件名 / 窗口类 / 通配符;可拖动排序(最上者优先)、套用一次、默认语言。

游標輸入指示器Caret input indicator光标输入指示器

游標旁顯示你實際會打出的:中/あ/한、Ａ(英數)或語言碼。預設關閉。An indicator beside the caret showing what you'll actually type: 中/あ/한, Ａ, or a language code. Off by default.光标旁显示你实际会打出的:中/あ/한、Ａ(英数)或语言代码。默认关闭。

工作列／開始搜尋框、Windows 終端機與檔案總管不會顯示輸入法指示器:這些系統層級介面僅允許具備數位簽章的程式顯示內容,而本工具目前尚未簽章。一般應用程式皆可正常顯示。The input indicator does not appear in the taskbar/Start search box, Windows Terminal, or File Explorer — system-level surfaces on which Windows permits only code-signed applications to display content (this utility is not currently signed).
