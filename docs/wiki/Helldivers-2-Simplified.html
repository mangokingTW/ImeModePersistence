在 Helldivers 2 中控制中文输入法

繁體中文 · English · 简体中文 · 日本語 · 한국어

Helldivers 2 目前无法可靠地处理中文输入法的状态。进入游戏时若系统还在中文模式，按键会被输入法拦走，而游戏内没有稳定的方式切回英数。

这一页说明怎么把这个游戏固定绑在英文输入语言上。

为什么一般的输入法工具在这里没用

游戏直接读取键盘，不接受一般程序用来切换输入法的那种指令。而且它的反作弊机制不让其他程序看见它是哪一个程序 —— 所以「指定某个可执行文件用英文」这种设置对它永远不会生效。

本工具改用两个方式绕过：用窗口类别（一种每个窗口都有的名称）来辨识它，并用 Windows 标准的「切换输入语言」通知请它自己换 —— 跟你按 Win+Space 时系统发的是同一种。

一件必要的前提：每次开玩前先提权

本工具必须以管理员身份运行，这个游戏才看得见。 游戏本身就是以管理员身份运行的，而 Windows 不让权限较低的程序读取权限较高的程序的窗口 —— 连窗口类别都读不到。

开机自动启动是普通权限（这是刻意的：开机就自动以管理员身份启动会被杀毒判成恶意）。所以每次开机后、要玩之前，先右键托盘图标 → 以管理员身份重新启动，过一次 UAC，它才看得到游戏。

没有提权的话，托盘提示的「当前程序」会显示 （未知），你连要填什么都看不到。

怎么确定它有提权： 把鼠标停在通知区域的图标上。若最后一行写着「普通权限 － 看不到提权的程序」，就是还没提权 —— 右键 → 以管理员身份重新启动。

设置步骤

  1. 从 Releases 下载 ...-setup.exe，安装时勾选 开机时自动启动（开机后以普通权限启动）。要控制游戏之前，记得先照上面「必要的前提」右键 → 以管理员身份重新启动。

    安装画面还有一个 绑定 Helldivers 2 为英文输入。勾了它，下面第 5～8 步就会在第一次启动时自动完成，你可以直接跳到「确认是否生效」。想自己手动设置、或想绑其他语言，就别勾，照下面走。

  2. 启动 Helldivers 2，然后按 Windows 键 叫出任务栏。

  3. 到通知区域找到图标 —— 屏幕右下角、时钟左边。Windows 11 默认把新图标收起来，要先点时钟旁的 ⌃ 才看得到。图标是蓝色圆角方块里一个白色的「中」。

  4. 先确认：把鼠标停在图标上，「当前程序」应显示 class:stingray_window。显示别的程序就代表会抓错，切回游戏重来。

  5. 在图标上按右键 → 程序绑定输入语言…

  6. 按 用窗口类别。字段会填入：

    class:stingray_window

  7. 输入语言 选 英文 (美国)，或你想固定的语言。

  8. 按 新增／更新。列表里会出现这条规则。

  9. 回到游戏。输入语言会自动切换。

你不需要自己查那串 class:stingray_window —— 用窗口类别 会用你切过来之前那个程序自动填好。

确认是否生效

把鼠标停在通知区域的图标上，不要点它。停留就会显示状态；点下去会让游戏失去焦点，你看到的就不是它了。

成功时应该是：

行 内容
当前程序 class:stingray_window
绑定语言 英文 (美国)
实际语言 英文 (美国)
上次切换尝试 已生效

「当前程序」显示 class: 而不是文件路径是正常的，不是故障 —— 反作弊不让任何程序读取它的位置，所以本工具改用它唯一看得到的辨识方式。

只想要游戏的规则，不要全局行为

本工具默认会把你最后选的输入模式带到下一个窗口。如果你只想要「游戏固定英文」，在右键菜单取消勾选 跨程序维持输入模式。绑定规则不受影响。

疑难解答

症状 处理
当前程序显示 （未知） 本工具没有以管理员身份运行。托盘菜单 → 以管理员身份重新启动
当前程序显示 class:stingray_window 正常，继续设置就好
绑定语言显示 （无规则） 规则没对上。核对列表里的内容与提示文字显示的 class: 完全一致
列表里出现的是别的程序 抓错了。选取该条按 删除选取的规则，回游戏重来
上次切换尝试显示未生效 切换没成功。欢迎反馈，但请看下面「不会做的事」

它对游戏做了什么、没做什么

完全没有做的事：不修改游戏文件、不读写它的内存、不注入代码或 DLL、不在它里面建立线程、不挂钩它、不装驱动程序、不模拟按键、不附加调试器。

只做这些：读取「哪个窗口在最前面」和「那个窗口的类别名称」（每个窗口都有的公开属性，任何程序都在读）、询问一次它的文件位置（会被拒绝），然后请游戏窗口自己切换 —— 投递 Windows 标准的「切换输入语言」通知，跟你按 Win+Space 时系统发出的是同一种，窗口可以自行忽略。如果没有生效，改请 Windows 自己的输入法设置去切换，那一步完全不接触游戏。

（v0.7.1 到 v0.9.1 曾改成对这类程序完全不发送消息、只走操作系统那条路 —— 实测那样根本切换不了语言，v0.9.2 起恢复。旧版说明里「不发送任何消息」的讲法以本页现在的叙述为准。）

这样就一定不会被封吗？ 没有人能保证反作弊系统的判断，我也不能。上面是完整清单，你可以据此自行判断，或拿去问官方客服。如果你不愿承担任何残余风险，最安全的做法就是不要在游戏运行时使用任何第三方工具，改用手动切换输入法。

其他游戏

同样的做法适用于任何看不到可执行文件的程序：用窗口类别 按钮会自动填入该程序的类别，不必知道它叫什么。用同一套引擎开发的游戏，类别名称可能相同。
