Helldivers 2에서 중국어 IME 제어하기

繁體中文 · English · 简体中文 · 日本語 · 한국어

Helldivers 2는 IME 상태를 안정적으로 처리하지 못합니다. 게임에 진입할 때 시스템이 중국어 모드이면 키 입력이 IME에 가로채이며, 게임 내에서 영숫자로 되돌아갈 믿을 만한 방법이 없습니다.

이 페이지에서는 게임을 영어로 고정합니다.

이 유틸리티는 개발 중이며 서명되지 않았고, 백신이 이를 바이러스로 분류하여 삭제할 수 있습니다. 자세한 내용은 홈 페이지를 참고하고, 사용할지 여부를 직접 판단하세요.

일반적인 IME 도구가 여기서 실패하는 이유

이 게임은 키보드를 직접 읽으며, 다른 프로그램이 입력 언어를 전환할 때 사용하는 종류의 명령을 받아들이지 않습니다. 또한 이 게임의 안티치트는 다른 프로그램이 이것이 어떤 프로그램인지 알아내는 것을 막습니다 — 그래서 실행 파일 이름을 지정하는 규칙은 결코 적용되지 않습니다.

이 유틸리티는 두 가지 모두를 우회합니다: 창을 그 클래스(모든 창이 가지는 이름)로 식별하고, Windows의 표준 입력 언어 변경 알림으로 전환을 요청합니다 — Win+Space를 눌렀을 때 시스템이 보내는 것과 동일한 것입니다.

한 가지 요구 사항: 매 세션마다 권한을 올려야 합니다

유틸리티는 관리자로 실행되어야 하며, 그렇지 않으면 이 게임을 전혀 볼 수 없습니다. 게임 자체가 관리자로 실행되며, Windows는 권한이 낮은 프로그램이 권한이 높은 프로그램의 창을 읽는 것을 허용하지 않습니다 — 창 클래스조차도 읽을 수 없습니다.

자동 시작은 권한 상승 없이 실행됩니다(의도적입니다: 매 로그온마다 조용히 권한 상승 상태로 시작하는 프로그램은 백신이 지목하는 지속성 패턴입니다). 따라서 매번 부팅 후, 플레이하기 전에 트레이 아이콘을 오른쪽 클릭 → 관리자로 다시 시작을 선택하고 UAC 프롬프트를 수락하세요 — 그래야만 게임을 볼 수 있습니다. 그렇게 하지 않으면 앱 줄에 (unknown)이라고 표시되어 입력할 대상이 없습니다.

단계

  1. Releases에서 ...-setup-admin.exe를 설치하고, 로그온 시 자동 시작을 체크하세요(로그온 시 권한 상승 없이 시작됩니다). 게임을 제어하기 전에 위 요구 사항을 기억하세요: 오른쪽 클릭 → 관리자로 다시 시작.

    설치 프로그램은 Helldivers 2를 영어 입력으로 바인딩도 제공합니다. 이를 체크하면 아래 5–8단계가 첫 실행 시 자동으로 수행됩니다 — "작동 확인하기"로 건너뛰세요. 규칙을 직접 설정하거나 다른 언어로 바인딩하려면 체크하지 않은 채로 두세요.

  2. Helldivers 2를 시작한 다음, Windows 키를 눌러 작업 표시줄을 띄웁니다.

  3. 화면 오른쪽 아래에서 트레이 아이콘을 찾습니다 — Windows 11은 새 아이콘을 시계 옆의 ⌃ 꺾쇠 뒤에 숨깁니다.

  4. 먼저 확인: 아이콘에 마우스를 올리세요; 앱 줄에 class:stingray_window가 표시되어야 합니다. 다른 것이 표시되면 잘못된 프로그램을 잡게 되므로 — 게임으로 돌아가 다시 시도하세요.

  5. 오른쪽 클릭 → 앱 언어 바인딩...

  6. 창 클래스 사용을 누릅니다. 필드가 class:stingray_window로 채워집니다.

  7. 언어에서 English (United States)를 선택합니다.

  8. 추가 / 업데이트를 누릅니다.

  9. 게임으로 돌아갑니다.

그 클래스를 직접 찾아볼 필요는 없습니다 — 버튼이 마지막으로 머물렀던 프로그램에서 자동으로 채워줍니다.

작동 확인하기

트레이 아이콘에 마우스를 올리세요; 클릭하지 마세요. 클릭하면 게임이 포커스를 잃어 잘못된 정보를 보게 됩니다. 성공하면 앱 줄에 class:stingray_window가 표시되고, 바인딩된 언어와 실제 언어가 일치하며, 마지막 시도가 적용되었다고 표시됩니다.

파일 경로 대신 class:가 표시되는 것은 예상된 것이지 결함이 아닙니다: 안티치트가 게임의 위치를 읽는 것을 막으므로, 유틸리티는 볼 수 있는 유일한 식별자를 사용합니다.

게임 규칙만 원하는 경우

트레이 메뉴에서 창 간 모드 유지의 체크를 해제하세요. 바인딩은 계속 작동합니다.

문제 해결

증상 조치
앱이 (unknown)으로 표시됨 관리자로 실행되고 있지 않습니다. 트레이 메뉴 → 관리자로 다시 시작
바인딩된 언어가 (no rule)로 표시됨 규칙이 매칭되지 않습니다. 툴팁에 표시된 class: 문자열과 정확히 일치하는지 확인하세요
목록에 다른 프로그램이 표시됨 잘못된 프로그램을 잡았습니다. 그것을 선택하고 선택 항목 제거를 누른 뒤, 게임으로 돌아가 다시 시도하세요
마지막 시도가 적용되지 않았다고 표시됨 신고해 주세요. 다만 아래 내용을 참고하세요
업데이트 시 프로그램을 닫으라고 요구함 관리자 권한이 없는 설치 프로그램을 사용하고 수동으로 권한을 올렸습니다. ...-setup-admin.exe로 다시 설치하세요
로그온 시 시작되지 않음 설치 중 또는 트레이 메뉴에서 로그온 시 자동 시작을 체크하세요 — 권한이 상승된 상태에서는 권한 상승된 예약 작업을 등록합니다

이 유틸리티가 하지 않는 것

게임을 수정하거나, 메모리를 읽거나, 게임에 간섭하지 않습니다. 전환은 게임의 창에 전환을 요청하는 방식으로 작동합니다 — Windows의 표준 입력 언어 변경 알림을 게시하는 것으로, Win+Space를 눌렀을 때 시스템이 전달하는 것과 동일하며, 창은 이를 무시해도 됩니다 — 그런 다음 Windows 자체의 입력 설정으로 대체합니다. 둘 중 어느 것도 적용되지 않으면 무엇도 강제하지 않고 조용히 포기합니다 — 그런 기법이야말로 안티치트가 잡아내려는 대상이며, 오탐 하나가 계정을 잃게 만들 수 있기 때문입니다.

(v0.7.1과 v0.9.1 사이에서 이 유틸리티는 그런 프로그램에 아무런 메시지도 보내지 않고 Windows 쪽 경로만 사용했습니다. 그 방식은 언어를 전환하지 못하는 것으로 드러났고, v0.9.2에서 알림을 복원했습니다. 이전 페이지에서 "메시지를 보내지 않는다"고 한 곳이 있다면, 이 설명이 그것을 대체합니다.)

다른 게임

동일한 방식은 실행 파일을 볼 수 없는 모든 프로그램에 적용됩니다: 창 클래스 사용이 그 클래스를 자동으로 채워줍니다. 같은 엔진으로 만들어진 게임은 클래스 이름을 공유할 수 있습니다.
