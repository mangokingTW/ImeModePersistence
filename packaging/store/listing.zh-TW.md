## 2. 說明（Description）

一個常駐通知區域的小工具，控制輸入法在程式之間的行為。它做兩件事：把你**最後選擇的輸入模式**（中文／英數）延續到下一個視窗，並可把指定程式**綁定到固定的鍵盤輸入語言** —— 包含連執行檔都讀不到的程式，例如有防作弊的全螢幕遊戲。

**讓轉換模式在視窗之間保持一致。** Windows 把輸入法狀態綁在**每個執行緒**上，所以切到另一個視窗時，中／英轉換模式會回到該輸入法的預設值 —— 對中文鍵盤來說就是**中文**。你剛按 Shift 切成英數、換個視窗，又打出中文。「設定 → 時間與語言 → 輸入 → 進階鍵盤設定」裡的**「允許我為每個應用程式視窗使用不同的輸入法」解決不了這件事**：那個設定管的是「哪一個輸入法在作用」，不管「該輸入法處於中文還是英數」。**沒有任何 Windows 設定能處理轉換模式** —— 這個工具可以：你選的中／英模式會跟著你走到下一個視窗，也可以從托盤選單關閉。已在實機上與**微軟注音**確認可用。

**把程式綁定到某個輸入語言。** 終端機綁英文、Word 綁中文，各自固定不動。規則的比對方式有三種：以**完整路徑**（瀏覽選執行檔，所以兩個同名程式可以分開設定）、以純**檔名**（`notepad.exe`，不管裝在哪）、或以**視窗類別**（`class:<類別名>`）。視窗類別是唯一能處理**使用 raw input 的全螢幕遊戲**的方式：它直接讀取鍵盤裝置，完全不參與輸入法的狀態管理，路徑連管理員也讀不到 —— 只能從外部處理。**已確認可用於有防作弊的全螢幕遊戲**（Helldivers 2 用 `class:stingray_window`）。可拖拉規則調整優先順序（第一個符合的生效）、把任一規則設為「切換時只套用一次」，或設一個預設語言給比不到的程式。

**游標輸入指示器。** 可選擇在文字游標旁顯示一個小徽章，告訴你目前**會打出什麼**：`中`／`あ`／`한`（該語言的輸入模式）、`Ａ`（輸入法切到英數）、或 `EN` 等語言代碼。**預設關閉**，設定會記住。

**提權。** 讀取或修改**提權程式**的視窗需要同等權限。當目標需要系統管理員權限時，App 會提示你，托盤選單的**以系統管理員身分重新啟動**可以當場提權。另有可選的診斷記錄，會記下每次上下文切換、規則是否比對成功、以及切換用了哪個機制，方便排查問題。

**關於市集版。** Microsoft Store（MSIX）版**無法提權**，所以碰不到以系統管理員執行的程式或反作弊遊戲。那類目標請改用**桌面版**（安裝檔／Scoop／winget）並以系統管理員執行。市集版**支援「開機時啟動」**。

不注入、不掛勾、不模擬按鍵。切換是向視窗投遞 Windows 標準的「切換輸入語言」通知（視窗可自行忽略），行不通再退回以 TSF 的公開 API 切換；是 best-effort，並會讀回狀態驗證。介面依 Windows 顯示語言選擇（英文、繁體中文、簡體中文、日文、韓文）。

**功能重點**

- 把你選的中／英轉換模式延續到下一個視窗 —— 這是沒有任何 Windows 設定能處理的一件事。
- 依程式綁定輸入語言，可用完整路徑、檔名、或視窗類別。
- 視窗類別綁定能處理讀 raw input、且無法用其他方式比對的反作弊全螢幕遊戲。
- 可選的游標輸入指示器，在你打字的位置直接顯示目前輸入狀態。
- 目標需要管理員權限時會提示提權，並提供「以系統管理員身分重新啟動」。
- 市集版無法提權（管理員／反作弊目標請用桌面版）；市集版支援「開機時啟動」。
- 不注入、不掛勾、不模擬按鍵 —— best-effort 並讀回驗證。
- 英文、繁體中文、簡體中文、日文、韓文介面，依 Windows 顯示語言自動選擇。
